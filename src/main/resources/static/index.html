THE RULES OF THE BOOK

Price. Then patience.

A better price always goes first. At the same price, the first accepted order wins. Trades execute at the resting order’s price.

TRY THIS ON AN EMPTY BOOK

  1. Sell 5 units at $100.00, then sell 5 more at $100.00.
  2. Buy 7 at $100.00. The first sell fills; the second has 3 left.
  3. Find the second sell in tracked orders and cancel it.

For a multi-level sweep, run ./scripts/demo.sh locally.
